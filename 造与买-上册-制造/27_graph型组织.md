# graph 型组织

组织图的形状，从来不是人画出来的，是它脚下的协调技术画好的。

## 三家在争同一张图

微软 2025 年拿出 Work Chart。麦肯锡 2026 年 4 月拿出 Agentic Mesh。还有人叫它 Execution Graph。

三个名字，争的是同一个位置：一张把人和 agent 摆在一起的画布。

它们的共同点只有一句：任务成为单元。人和 agent 不再分属两个世界，落在同一张图上，按同一件事排。

它像当年的组织架构图。谁画，谁定标准。谁先定义这张图，谁就定义了下一种公司的样子。

名字不同，赌注一样：谁的标准被采用，谁的软件就坐在所有公司的中枢上。

## 图的样子是技术画的

回头看，每一代组织图的轮廓，都由它下面那层协调技术决定。

不是哪任 CEO 的品味，也不是哪本书的理论。技术先把可能画出来，人再走进去。

人能想象的形状，总被当时能传的信、能存的记忆框住。CEO 年年重画架构图，形状却总会弹回原处。因为弹回的那个，是当时能跑通的唯一形状。

人画得出图，画不出图底下的带宽。带宽到了，形状才肯变。

前面讲过两次这样的时刻。把它们摆在一起，规律就清楚了。

## 电报与维基各画了一代

电报加上时刻表，画出了泰勒的金字塔。命令能先于货物到达，计划部门就能把动作拆到秒，再一层层压下去。等级不是天生的，是那时最快的传信方式长出来的。

维基加上即时通讯，画出了扁平。知识能当场共享，上下文不必经人手转递，中间那层搬运工就没了活干。扁平不是谁提倡的，是工具先让中间层没活干。

维基让任何人改任何页；即时通讯让上下文全量留存。两者合起来，协作不再必经一个主管的嘴。

前面那次扁平实验，卡在考核没跟上，但图的形状已经露出来了。两代，两个形状，两套协调技术。没有一个是被设计出来的。

## 记忆智能执行同画布

这一代的底牌是三样东西同处一张画布：记忆、智能、执行。

从前这三样散在别处。记忆躺在邮件里，智能长在人对事的判断里，执行关在系统里。现在被摁到同一个平面。

记忆让 agent 记得上一次怎么干。智能让它自己决定下一步。执行让它真的把事做完。

从前换一个人接手，要先读三个月邮件。现在 agent 接着上次的上下文干。组织不再是一张汇报线，而是一张任务流。人在流里补判断，agent 在流里跑工序。

画布的意思是，人和 agent 共用一套坐标。同一件事，谁在做、做到哪，一眼看得见。

三样同处一画布，才第一次让**人和机器一起排活**不再是比喻。

## 旧道路挡住新网络

前面那套 ERP 会挡路。

ERP 把企业画成一条固化的道路：岗位、流程、审批，全焊死在表里。一条固定的路，不可能是一个实时反应的网络。

ERP 编码的，正是上一代的协调技术。ERP 的好处是稳，坏处是定，它把上世纪最好的协调方式冻成了表。给旧系统加一层 AI，只是在旧路上铺新漆。

真正的迁移是重写运行体系——把道路拆了，换成能随任务重组的网。加一层 AI 在旧路上，只是新天轴：机器换了，布局没动。
