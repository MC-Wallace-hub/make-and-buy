# make-and-buy
# 造 / 买

一套两册的非虚构书稿，讲工业时代的两条线。

## 两册

**上册《造》· 工业生产史**（29 个单元）
从 1771 年水边那座纱厂写到今天的智能体调度。主线是**生产中人的位置**：手艺人自己拿主意 → 工厂把决定权收走 → 泰勒把思考搬进办公室 → 福特把活拆到谁都能做 → 丰田把判断编回机器 → 算法再收走一次。

**下册《买》· 工业消费史**（22 个单元）
从集市写到 agent 代买。主线是**分发权**：谁决定你能看见什么，谁就决定什么卖得掉。这条权力换了五次手——货架位置 → 电视时段 → 搜索排名 → 推荐 → agent（最后一环还空着）。

## 两个机制

- **适配时滞**：技术进来了，布局没动。1882 年电就到了，可接下来四十年工厂几乎没变——不是机器的问题，是厂房还按天轴排着。
- **分发权就是定义权**：定义生产的最后一个环，入口在消费那一侧。这是两册的交汇处。
